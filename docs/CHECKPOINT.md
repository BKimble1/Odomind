## Environment constraints that shaped the build

- No Swift toolchain on the authoring host; `download.swift.org` blocked.
  **The macOS CI runner is the compiler.** Expect a push-compile-fix loop.
- `vpic.nhtsa.dot.gov` blocked from the authoring host. Provider code is tested
  against recorded fixtures in `OdomindTests/Fixtures/`; live availability is
  checked by the separate, optional `provider-smoke` workflow.
- Manufacturer sites blocked. This is why the catalog ships no manufacturer
  specification values.

## Commands

```bash
# Portable core — fast, no simulator
swift build --package-path OdomindCore
swift test  --package-path OdomindCore --parallel

# Catalog gate
swift run --package-path OdomindCore odomind-catalog validate \
  OdomindCore/Sources/OdomindCore/Resources/odomind-catalog.json --strict

# Regenerate the project after adding or moving files
python3 Tools/generate-xcodeproj.py

# Regenerate the app icon
python3 Tools/make-app-icon.py

# iOS build and tests (macOS only)
DEST="$(MIN_IOS_MAJOR=18 ./.github/scripts/select-simulator.sh)"
xcodebuild build-for-testing -project Odomind.xcodeproj -scheme Odomind \
  -destination "$DEST" CODE_SIGNING_ALLOWED=NO
xcodebuild test-without-building -project Odomind.xcodeproj -scheme Odomind \
  -destination "$DEST" -only-testing:OdomindTests CODE_SIGNING_ALLOWED=NO
```

## Notes for whoever picks this up

- `ScheduleEngine` is pure on purpose. If a change needs a clock, a locale or a
  store inside it, the change belongs somewhere else.
- The catalog validator is the guard rail on honesty. If a change requires
  loosening it, that is the signal to stop and reconsider the change.
- Adding files outside Xcode means running `Tools/generate-xcodeproj.py`; CI
  will fail the `project-is-reproducible` job otherwise.
- `AppModel.uiTestingArgument` gives UI tests a throwaway store. Keep it.

## Remaining and deliberately not done

- Swift 6 strict concurrency migration.
- A hosted catalog with signed manifests and last-known-good fallback.
- Device-only verification: real notification delivery, the calendar editor, the
  camera VIN scanner. These cannot be exercised on a simulator and are listed in
  the README as outstanding rather than claimed as tested.
- Localisation beyond English. The formatting layer is locale-aware; the strings
  are not yet extracted.
